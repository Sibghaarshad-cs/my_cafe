
# Brew & Bloom Cafe Website

Brew & Bloom is a responsive cafe website designed to showcase cafe menus, specialities, and information while allowing visitors to make table reservations. It is developed using HTML, CSS, and JavaScript.

## Features

- Home page
- Menu page
- Specialities page
- About page
- Table booking form
- Form validation
- Light/Dark theme toggle
- Interactive JavaScript features

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Use

1. Open the live website using the link below.
2. Navigate through the Home, Menu, Specialities, About, and Booking sections/pages.
3. Explore the menu and cafe specialities.
4. Use the booking form to enter your details.
5. Try the theme toggle.

To run locally, download or clone this repository and open `index.html` in your browser.
